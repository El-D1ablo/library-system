# Библиотечная система (library-system)

Учебный проект по дисциплине «Технологии программирования»
(практическая работа 6 «Управление версиями программного проекта с использованием Git и GitHub»).

## Назначение

Консольное приложение для учёта книг небольшой библиотеки: ведение каталога книг,
поиск, выдача книг читателям и их возврат.

## Цель проекта

Отработать организацию разработки с помощью Git и GitHub: декомпозицию проекта
на задачи (Issues), оценку трудоёмкости методом PERT, разработку в отдельных ветках,
Pull Request и Code Review, документирование и выпуск версии.

## Основные предполагаемые функции

- добавление книги в каталог с проверкой данных;
- просмотр списка книг;
- поиск книг по названию и автору;
- удаление книги;
- сохранение и загрузка каталога (JSON);
- учёт читателей, выдача и возврат книг.

## Язык и инструменты

- Python 3.8+ (только стандартная библиотека)
- Git, GitHub (Issues, Pull Requests, Code Review)
- Visual Studio Code
